# Horse Stable Manager

## Case Study

Horse Stable Management System.

This application manages horse records using a **Doubly Linked List**.

## Technologies

- Python
- Tkinter
- Object-Oriented Programming
- Doubly Linked List

## Project Structure

```text
HorseStableManager/
├── main.py
├── horse.py
├── doubly_linked_list.py
├── ui.py
└── assets/
```

## Run the Application

Open the project folder in VS Code and run:

```bash
python main.py
```

No external Python packages are required.

## Doubly Linked List Operations

The application demonstrates:

- Insertion
- Deletion
- Search
- Update
- Forward traversal
- Backward traversal
- Next node navigation
- Previous node navigation

Each node contains a horse and two references:

```text
previous ⇄ current ⇄ next
```

The complete list follows:

```text
HEAD ⇄ Horse ⇄ Horse ⇄ Horse ⇄ TAIL
```

## Interface

The graphical interface includes:

- Dashboard statistics
- Horse records table
- Add horse window
- Edit horse window
- Search
- Delete
- Previous / Next navigation
- Forward / Backward traversal
- Visual representation of HEAD and TAIL

All interface text and source-code identifiers are written in English.
